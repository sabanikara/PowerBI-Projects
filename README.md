Online Retail Sales Dashboard

An interactive sales dashboard built with Microsoft Power BI to analyze online retail sales performance, customer behavior, and revenue trends.

📊 Dashboard Overview

The dashboard provides a clear overview of sales performance through interactive KPIs, charts, and filters.

Key KPIs

* Total Revenue: 9.75M
* Total Orders: 26K
* Total Quantity: 5M
* Average Order Value: 376.36

📈 Visualizations

* Revenue by Country
* Revenue by Product
* Monthly Revenue
* Yearly Revenue
* Top 10 Customers by Revenue
* Quarterly Revenue

🎛 Interactive Filter

* Country Filter

🛠 Tools & Skills

* Power BI
* DAX
* Data Modeling
* Data Visualization
* Business Intelligence

📷 Dashboard Preview

🎯 Project Objective

The goal of this project was to transform raw retail sales data into an interactive and visually clear dashboard that helps users understand revenue performance across countries, products, customers, and time periods.

📌 Key Features

* Interactive country filtering
* KPI-based performance overview
* Revenue analysis by country and product
* Monthly, quarterly, and yearly revenue analysis
* Customer revenue analysis
* Clean and user-friendly dashboard design
