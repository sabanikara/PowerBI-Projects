# Retail Sales & Inventory Dashboard – Power BI

## Project Overview

This project is a Power BI dashboard developed to analyze retail sales and inventory data.

The dashboard provides an overview of key business metrics and allows users to explore sales and inventory performance across different product categories, stores, locations, and cities.

## Dashboard Analysis

The dashboard includes:

- Total Revenue
- Total Profit
- Total Units
- Revenue by Product Category
- Revenue and Profit by Product Category
- Revenue by Store
- Revenue by Store Location
- Revenue by Store City
- Stock On Hand by Product Category
- Stock On Hand by Store
- Revenue Trend over Time

## Interactive Filters

The dashboard includes interactive slicers for:

- Product Category
- Store Location
- Store City

## Data Model

The analysis uses the following data tables:

- Sales
- Products
- Stores
- Inventory
- Dates

## Tools Used

- Power BI
- DAX
- Data Modeling
- Data Visualization

## Project Outcome

The final result is an interactive Power BI dashboard that provides a clear view of retail sales, profitability, and inventory performance and enables users to analyze the data from different business perspectives.
