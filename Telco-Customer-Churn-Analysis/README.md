📊 Telco Customer Churn Analysis

An interactive Customer Churn Analysis Dashboard built using SQL Server and Power BI to analyze customer behavior and identify patterns associated with customer churn.

🎯 Project Overview

This project analyzes 7,043 customer records from a telecommunications company.

The analysis focuses on customer churn and key business metrics, including:

* Total Customers
* Churned Customers
* Churn Rate
* Average Monthly Charges

🔍 Analysis

Customer churn was analyzed across:

* Contract Type
* Payment Method
* Internet Service
* Gender
* Senior Citizen

An interactive Power BI dashboard was created using KPIs, visualizations, and slicers to enable dynamic data exploration.

🛠 Tools & Technologies

* SQL Server
* Power BI
* DAX
* Power Query
* Data Modeling
* Data Visualization

📊 Dashboard

The dashboard provides an interactive view of customer churn patterns and key performance indicators.

📂 Dataset

The dataset is publicly available on Kaggle:

Telco Customer Churn — Kaggle
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The dataset was originally provided as an IBM sample dataset and contains customer demographic, service, account, and churn information.
